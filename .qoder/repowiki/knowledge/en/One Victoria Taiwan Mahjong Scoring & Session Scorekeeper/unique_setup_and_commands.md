Run the static site with `python -m http.server 8000` and open `http://127.0.0.1:8000/mahjong-suite/index.html` (guest) or `session-scorekeeper-online/index.html` (account). Start the backend with `mvn -f backend/pom.xml package && java -jar backend/target/mahjong-scorekeeper-backend-1.0.0.jar` (defaults to H2 on `http://127.0.0.1:8080/api`). Run browser suites via `python run_tests.py --browser all --timeout 120` and `python run_scorekeeper_tests.py --browser all --timeout 120`; backend tests via `mvn -f backend/pom.xml test`. Results are persisted under `test-results/`.
