Single-page HTML shell (`index.html`) hosts two child apps via `<iframe>` elements: `../session-scorekeeper/index.html` (the round/session scorekeeper) and `../mj.html` (the per-hand type calculator). `app.js` is an IIFE orchestrator that reads URL query params (`account`, `embedded`, `shellTest`) to toggle guest vs. account mode and embedded styling, then drives view switching between the two panels via `data-suite-view`/`data-suite-panel` attributes on the root element. Cross-frame communication uses custom DOM events: the calculator exposes `window.OVMJCalculator` with an `eventName` and `getLastResult()`; the suite polls for it (`connectCalculator` / `waitForCalculator`) and subscribes to its event stream, validating payloads against a fixed schema version `ov-mj-calculation-result/v1`. The scorekeeper is accessed through a delegated host object (`delegatedHost()`) that forwards calls like `getSession`, `fillRoundDraft`, `createSession` to `scorekeeperFrame.contentWindow.OVMJSessionHost`, guarded by a `hostReady` Promise resolved when the iframe signals readiness or rejected on error/timeout. A floating transfer tray (`#suite-transfer`) displays computed fan values and lets the user apply the latest result back into the scorekeeper's round draft. CSS variables define a green/gold theme, and responsive rules adapt layout for mobile and embedded contexts.
