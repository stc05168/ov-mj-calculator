This module is a pure documentation package under `docs/` that defines the project's authoritative sources of truth for the mahjong-suite frontend, session-scorekeeper, and Spring Boot backend. `ARCHITECTURE.md` documents the three-layer separation (single-round scoring, full-session scorekeeping, account persistence), the iframe-based guest vs. logged-in data flows, the immutable `OVMJSessionHost` facade boundary, the online adapter's optimistic locking and workspace lifecycle, and the Java backend boundaries (AuthInterceptor, AuthService, ApiController, JPA entities). `RULES.md` codifies the v2.7 rule set: hand model, four-stage scoring pipeline (collect → detect → exclude → post-process), name matching with parameterized families, the v2.7 no-honor non-stacking amendment, the 嚦咕嚦咕 honor-pair amendment, ordinary honor preservation, centralized exclusion via `EXCLUSION_RULES`, and the 大雞糊/鴨糊 low-score fallback. Supporting files (`DEPLOYMENT.md`, `FULL_STACK.md`, `SESSION_SCOREKEEPER.md`, `TESTING.md`, `UNIFIED_APP.md`, `USER_GUIDE.md`) cover deployment topology, end-to-end stack wiring, session replay/settlement semantics, browser+Java test harnesses, unified app integration, and user workflows. Dependency direction is one-way: docs describe code in `mahjong-suite/`, `session-scorekeeper/`, `session-scorekeeper-online/`, and `backend/src/main/`; there are no runtime imports from this directory.
