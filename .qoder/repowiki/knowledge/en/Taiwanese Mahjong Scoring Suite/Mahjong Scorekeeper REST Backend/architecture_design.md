Single-module Spring Boot 3 application (Java 17) organized in a classic layered layout under `com.onevictoria.mahjong`: `web` exposes `@RestController` endpoints under `/api`, an `AuthInterceptor` enforces Bearer-token auth via `HandlerInterceptor` for all paths except health/register/login, and `WebConfig` registers the interceptor plus CORS. `service.AuthService` encapsulates account registration, login, token issuance/revocation using BCrypt passwords and SHA-256 hashed tokens stored in `repo.ApiTokenRepository`. `model` JPA entities (`Account`, `ApiToken`, `GameSession`, `PlayerProfile`) map to tables and are accessed through Spring Data JPA repositories in `repo`. `GameSession` stores the full game payload as a serialized JSON string with a `schemaVersion` field (`ov-mj-session/v1`) and optimistic-lock `@Version`; `ApiController.putSession` validates incoming payloads against this schema (4 players, valid entry types, numeric ranges, physical seat mapping) before persisting, and provides JSON/text export endpoints. `ApiExceptionHandler` + `ApiProblem` centralize error responses. Configuration is split across `application.properties` (defaults) and `application-postgresql.properties` (profile-specific DB settings), with H2 as the default runtime database.
