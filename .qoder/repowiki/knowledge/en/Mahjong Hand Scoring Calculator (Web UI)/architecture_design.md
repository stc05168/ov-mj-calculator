The app is a flat, vanilla-JS SPA loaded by `mj.html`, styled by `mj.css`, and composed of three JS modules with one-way dependency direction: `mjConst.js` defines the canonical tile model (`TILE_TYPES`, `ALL_TILES`, `FLOWER_TILES`); `mj.js` owns the global `state` object (hand tiles, flowers, chows/pungs/kongs, winning tile, seat/round wind, dealer flags, history) and handles all DOM interaction — rendering tile palettes, drag-and-drop (mouse + touch) into hand/winning/trash zones, button-driven meld creation (chow/pung/open-kong/concealed-kong), undo/clear, and wiring every form control to mutate state and call `calculateScore()`; `checkHandType.js` is the pure scoring engine that reads the shared `state` plus the tile data from `mjConst.js`, runs a cascade of pattern detectors (e.g. `isShiSanYao`, `isPingHu`, `isDuiDuiHu`, dragon/sister/yaojiu/gaoxiang routines), applies an `EXCLUSION_RULES` table for mutually exclusive hand types, optionally wraps results in `大雞糊/鴨糊`, and returns a sorted list of `{ name, score }`. There is no build step or framework — files are served directly as static assets.
